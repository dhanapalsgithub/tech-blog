Next.js 15 introduces a refined **App Router**, streaming, and a richer set of Server Components primitives. This guide is a working blueprint you can copy into any production project.

## Why the App Router?

The App Router is not just a rename of the pages directory — it is a fundamentally different mental model. Every route is a **React Server Component** by default, which means:

- Zero JavaScript shipped for static content
- First-class streaming with `<Suspense />`
- Colocated `loading.js`, `error.js`, `not-found.js`

```txt
  posts.ts
components/
  AdSlot.tsx
```

## Performance Tips

1. **Static generation first** — use `generateStaticParams` for every blog route.
2. **Optimize images** — always reach for `next/image` with explicit dimensions.
3. **Font subsetting** — use `next/font` with `display: swap` for great LCP.
4. **Avoid client components** unless you truly need interactivity.
